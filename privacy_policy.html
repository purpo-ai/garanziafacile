2. Natura del servizio

GaranziaFacile è un'app offline 100% locale.

L'app è progettata per gestire garanzie d'acquisto, reclami e documenti esclusivamente sul dispositivo dell'utente. Non dispone di un backend, di un account online né di un database cloud personale.

I dati inseriti dall'utente vengono processati e memorizzati localmente in un file JSON all'interno della directory riservata dell'app (getApplicationDocumentsDirectory()), consultabile solo da GaranziaFacile stessa.

3. Dati trattati sull'apparecchio

Qualora utilizzi le funzionalità dell'app, i seguenti dati vengono creati e memorizzati esclusivamente sul tuo dispositivo:

  • Dati prodotto: nome, marca, modello, categoria, prezzo, data di acquisto, venditore, indirizzo venditore
  • Identificativi hardware: numero di seriale, codice a barre, codice IMEI — IMEI NON PIÙ RACCOLTO DALLA VERSIONE 1.0.0+1; è stato rimosso per conformità Google Play
  • Immagini: foto di ricevute, documenti scannerizzati, immagini di etichette — processate localmente tramite OCR
  • Testo OCR: testo estatto dalle immagini, elaborato on-device da Google ML Kit
  • Bozze e comunicazioni: reclami, lettere, comunicazioni generate localmente
  • Allegati: file PDF, immagini e documenti salvati nella cartella attachments/ locale
  • Notifiche locali: promemoria scadenze, programmati sul dispositivo
  • Impostazioni: preferenze dell'app, stato del setup, accettazione del disclaimer

Nessuno di questi dati viene mai inviato ai server del titolare né a terzi terzi.

4. Fotocamera e immagini

GaranziaFacile utilizza la fotocamera per:

  • Scansionare codici a barre (barcode scanner)
  • Scattare foto di ricevute e documenti per l'OCR
  • Acquisire immagini di etichette prodotti

La fotocamera non registra mai video né salva immagini autonomamente. L'immagine acquisita viene inviata all'elaborazione OCR su memoria e, se l'utente lo desidera, può essere opzionalmente salvata come allegato locale.

Nessuna immagine né alcun frame di contenuti viene mai trasmesso a server esterni.

5. OCR e Google ML Kit

L'app utilizza Google ML Kit Text Recognition (on-device), versione com.google.mlkit:text-recognition:16.0.1, per l'elaborazione OCR delle immagini di scontrini e etichette.

Il processo è il seguente:

  1. L'immagine viene caricata in memoria
  2. ML Kit elabora l'immagine localmente sul dispositivo (nessun upload)
  3. Il testo estratto viene utilizzato per compilare automaticamente i campi del prodotto

I contenuti dell'utente (immagini, testo OCR) non vengono mai inviati ai server Google né al titolare.

Tuttavia, ai sensi della documentazione ufficiale Google ML Kit, gli SDK ML Kit possono trasmettere a Google dati tecnici e diagnostici, tali come:

  • Informazioni sul dispositivo (modello, versione Android)
  • Informazioni sull'app (versione, package name)
  • Metriche di performance e utilizzo delle API
  • Identificatori tecnici di installazione
  • Eventi/Diagnostica per bug fixing e miglioramenti

Questi dati sono distinti dai contenuti personali (immagini, testo OCR) che l'utente elabora con l'app. Per informazioni dettagliate, consulta la pagina ufficiale ML Kit Data Disclosure.

6. Barcode Scanner e ML Kit

La scansione dei codici a barre utilizza ML Kit Barcode Scanning (on-device), versione com.google.mlkit:barcode-scanning:17.3.0.

Barcode e contenuti scansionati vengono processati localmente. Anche in questo caso, ML Kit può trasmettere dati tecnici secondo quanto descritto da Google.

7. Condivisione tramite sistema operativo

GaranziaFacile permette all'utente di condividere volontariamente documenti tramite il servizio di condivisione integrato nel sistema operativo (Android ACTION_SEND / iOS UIActivityViewController).

Questo avviene tramite la libreria share_plus, che:

  • Non raccoglie dati né trasmette nulla al titolare
  • Non invia dati a Google o a Firebase
  • Passa semplicemente i contenuti all'intent del sistema operativo
  • Lascia all'utente la scelta completa della destinazione

Qualsiasi condivisione avviene esclusivamente su esplicita azione dell'utente. Il titolare non ha alcun controllo su dove i dati vengano inviati né su come vengano trattati dal destinatario scelto.

Usare "Condividi" significa che l'utente intende attivamente far uscire i dati condivisi dal dispositivo.

8. Archiviazione e sicurezza

I dati dell'app vengono memorizzati in:

  • Un file JSON: garanzia_facile_data.json
  • Una cartella allegati: attachments/
  • Entrambi situati nella directory privata dell'app

Misure tecniche adottate:

  • ✅ Dati in una directory riservata del dispositivo (non accessibile ad altre app)
  • ✅ Nessun backup automatico su cloud (Google Drive, iCloud)
  • ✅ android:allowBackup="false" nel manifest
  • ✅ Nessun server backend né API network
  • ✅ Nessun database SQLite condiviso o file di log sensibili

Nessun dato personale viene mai trasmesso al titolare. L'esportazione JSON (funzionalità backup) viene salvata localmente e non viene mai caricata automaticamente.

9. Cancellazione dei dati

Po' eliminare definitivamente tutti i dati dell'app in qualsiasi momento:

Profilo → Impostazioni → Elimina tutti i dati

Questa operazione rimuove:

  • ✅ Il file garanzia_facile_data.json e tutti i prodotti, reclami, notifiche
  • ✅ Tutti gli allegati nella cartella attachments/
  • ✅ Tutte le notifiche locali programmate
  • ✅ Le impostazioni dell'app

La cancellazione è irreversibile. Puoi anche semplicemente disinstallare l'app per rimuovere tutti i dati.

Nota su "cancellazione account" di Google Play

Google Play richiede che le app che permettono la creazione di account online offrano una procedura di cancellazione account.

GaranziaFacile non offre account online né credenziali di accesso. Non viene pertanto richiesta alcuna credenziale. Per rimuovere i dati, utilizza semplicemente l'apposita funzione o disinstalla.
